# Data Cleaning & Preprocessing using MySQL

## Overview

A hands-on SQL project focused on cleaning and preprocessing
a real-world layoffs dataset using MySQL.

## Objectives

- Handle missing and null values
- Remove duplicate records
- Standardize inconsistent data
- Clean text and date fields
- Transform data for analysis
- Improve overall data quality

## Technologies

- MySQL
- SQL

## SQL Concepts Used

- UPDATE
- DELETE
- ALTER TABLE
- CASE
- String Functions
- Date Functions
- Aggregate Functions
- CTEs
- Window Functions

## Project Workflow

Raw Data
↓
Data Exploration
↓
Duplicate Removal
↓
Missing Value Handling
↓
Data Standardization
↓
Data Transformation
↓
Clean Dataset
